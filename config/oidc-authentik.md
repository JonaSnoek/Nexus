# NEXUS - SSO with Authentik

## Create the application

1. Admin UI -> Applications -> Applications -> Create.
   - Name: `NEXUS`
   - Slug: `nexus`
   - Launch URL: `https://nexus.example.com`
2. In the app, create a **Provider** (OAuth2/OpenID):
   - Client Type: Confidential
   - Redirect URIs: `https://nexus.example.com/auth/callback`
   - Signing Key: `Authentik Autogenerated Key`
   - **Scopes**: `profile`, `email`, `openid`
3. Copy the **Client ID** and **Client Secret**.

## Group mapping

You must expose the groups claim. In `authentik/lib/default` or the property
mapping for the provider:

```
# Protocol -> OIDC -> Property Mappings -> create "nexus-groups"
scope: groups
expression: return request.user.ak_groups.values_list("name", flat=True)
```

Create the groups `admins` and `users` (or whatever you set in `OIDC_GROUP_ADMINS`
and `OIDC_GROUP_USERS`), assign users, and select the mapping on the provider.

## .env

```dotenv
OIDC_ENABLED=true
OIDC_ISSUER_URL=https://auth.example.com/application/o/nexus/
OIDC_CLIENT_ID=<client-id>
OIDC_CLIENT_SECRET=<client-secret>
OIDC_REDIRECT_URI=https://nexus.example.com/auth/callback
OIDC_GROUP_ADMINS=admins
OIDC_GROUP_USERS=users
```

## OIDC endpoints used by NEXUS (Auto-Discovery)

- Configuration: `/.well-known/openid-configuration`
- Authorization: `/authorize`
- Token: `/token`
- UserInfo: `/userinfo`

NEXUS uses the issuer URL only and resolves the endpoints via discovery, so no
endpoint URLs need to be entered manually.
